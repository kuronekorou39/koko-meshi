# ココメシ (KokoMeshi)

「撮るだけ」で食事を全自動記録する食事ログ＆グルメマップアプリ。

料理の写真を撮るだけで、メニュー名・価格・カロリーをAIが端末内で自動推定。
写真も記録もすべて端末内に保存する完全ローカル動作で、アカウント登録は不要です。
外食・自炊・出前、すべての食事を記録します。

## 主な機能

- 料理写真の撮影・端末内保存（高画質オリジナル）
- AI（端末内Gemma）によるメニュー名・価格・カロリーの自動推定（オフライン・無料）
- 外食時のレストラン自動特定（GPS + Google Places API）
- パーソナル・グルメマップ（外食のピンを地図上に表示）
- 食事記録の一覧・フィルタリング
- 全データのzipバックアップ／別端末への移行

## 技術スタック

| 領域 | 技術 |
|---|---|
| モバイル | Flutter (Dart) |
| データ保存 | 端末内（SQLite + ローカルファイル）。クラウド不使用 |
| 画像解析（AI） | オンデバイス Gemma 4 E2B（端末内解析） |
| 地図 / 店舗特定 | Google Maps SDK + Places API |
| バックアップ / 移行 | zipエクスポート（archive）+ 共有シート（share_plus） |
