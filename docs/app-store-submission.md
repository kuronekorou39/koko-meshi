## 審査前にやること (コード側)

### 1. 「お店の検索（準備中）」ボタン — 対応済み

App Review ガイドライン 2.1 (App Completeness) は placeholder / "coming soon"
を差し戻し理由に挙げているため、配布ビルドでは検索ボタンを丸ごと出さない
ようにした (`map_tab.dart` / `AppFeatures.placeSearch`)。地図表示・記録・
マイプレイスはそのまま動く。

開発時は `--dart-define=PLACE_SEARCH=true` で従来どおり出せる。

### 2. Bundle ID の確認

現状 `com.kokomeshi.kokoMeshi` (Flutter が組織名から作った既定値)。
App Store Connect で新規 App を作るときに、この ID を登録する。
一度提出すると変更できないので、この ID でよいか先に決める。
OmniVerse は `com.rou39.omniverse` を使っている。

### 3. teamID / プロビジョニングプロファイル名

`ios/ExportOptions-AppStore.plist` には OmniVerse と同じ `M5D5CQRGX8` と、
プロファイル名 `KokoMeshi AppStore` を書いてある。Developer ポータルで作る
プロファイルの名前が違うなら、こちらを合わせる。

### 4. バージョン

`pubspec.yaml` は `0.9.4+17`。**ストア表示の Version は `1.0`** にする
(ビルド番号 17 はそのままでよい)。

## 概要 (4000 文字以内)

```
【ココメシとは】
ココメシは、食事の写真を撮るだけで記録が残る食事ログアプリです。
外食も、自炊も、出前も。撮った写真から料理名を自動で判定して、時系列とマップの両方で振り返れます。

【撮るだけ、が本当に撮るだけ】
写真を撮って保存すれば、そこで完了。
料理名の判定は裏側で進むので、待たされることはありません。
判定に自信があるときはそのまま記録され、迷ったときは候補が並ぶので選ぶだけ。もちろん手入力もできます。

【AIは、あなたの端末の中で動きます】
料理名の判定はクラウドではなく端末の中で完結します。
食事の写真がどこかのサーバーに送られることはありません。
初回だけAIモデルのダウンロード（約2.4GB・Wi-Fi推奨）が必要ですが、そのあとは通信なしで動きます。
AIを使わず、すべて手入力で記録することもできます。

【食べた場所が、地図になる】
記録した食事は地図にも並びます。
同じ場所・近い時間の食事は自動でまとめられるので、「あの店で何を食べたか」がすぐ辿れます。
自宅や職場は「マイプレイス」として登録でき、自炊や出前は地図には出さず一覧だけに残ります。
地図のラベル（駅名・地名・お店の名前など）は、必要なものだけ個別にオン・オフできます。

【ログインは、ありません】
アカウント登録もパスワードもありません。起動したらすぐ使えます。
記録・写真・位置情報はすべて端末の中だけに保存され、外部のサーバーには送られません。
広告もアプリ内課金も入っていません。

【バックアップ】
記録はまとめてZIPファイルに書き出せます。機種変更のときは、書き出したファイルから復元できます。
復元は「足りないものを追加する」方式なので、いまある記録が消えることはありません。

【主な機能】
■ 写真から食事を記録（撮影／ライブラリから選択）
■ 端末内AIによる料理名の自動判定と、候補からの選択・手入力
■ 時系列の一覧とカレンダー表示
■ 食べた場所を並べたグルメマップ
■ マイプレイス（自宅・職場などの登録）
■ 食事の種別（外食・自炊・出前）での絞り込み
■ ZIPでのバックアップと復元

【ご利用上の注意】
・AIによる料理名の判定は推測です。栄養管理やアレルギー対応の判断には使用しないでください。
・データは端末内にのみ保存されます。機種変更や初期化の前に、必ずバックアップを書き出してください。
```

## App プライバシー (Nutrition Label)

App Store Connect の「App のプライバシー」で聞かれる質問への回答。
**すべて「データを収集しない」で通る**（これは強い立ち位置なので、間違って
「収集する」にしないこと）。

| 質問 | 回答 |
|---|---|
| このAppはデータを収集しますか？ | **いいえ** |

補足: 位置情報は Google Maps Platform に送られるが、これは地図表示のために
端末から直接送られるもので、開発者が取得・保存するデータではない。Apple の
定義では「収集」に当たらない（サードパーティ SDK が独自に収集する場合は
別だが、Maps SDK の利用は Google のポリシー下にある）。判断に迷う場合は
「位置情報 → App の機能 → ユーザーにリンクしない」で申告しても通る。
